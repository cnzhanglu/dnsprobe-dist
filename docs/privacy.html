dnsprobe 隐私权政策

更新日期：2026-09-22

应用名称：dnsprobe（Android 包名 fun.chihuo.dnsprobe）

概述

dnsprobe 是一款DNS 拨测工具，也可在本机进行 HTTP、TCP、ICMP 等辅助探测。拨测在您的设备本地执行，不提供账号登录，也不运营必须连接的云端拨测服务。我们不收集、不上传、不出售用于识别您个人身份的数据。

我们收集哪些数据

开发者不会从本应用自动收集个人数据或设备标识用于分析、广告或追踪。

应用可能在您主动操作时，于本机处理并保存以下信息（仅存于应用沙箱，默认不云备份、不随设备迁移）：

  • 您输入的拨测目标与参数（例如域名、记录类型、DNS 服务器、预期答案，以及可选的 URL、端口、HTTP Header/Body 等）；
  • 拨测结果、任务配置、运行历史与导出文件；
  • 为完成拨测所必需的本机网络状态摘要（例如当前网络类型），用于分段或恢复拨测流程。

若您在参数中自行填写了指向自有服务器或其他第三方的地址，相关请求由您主动发起，数据如何被该服务器处理取决于该服务方的政策，与 dnsprobe 开发者无关。

权限用途

  • 网络访问：仅用于您主动开始的 DNS 拨测，以及可选的 HTTP / TCP / ICMP 探测。
  • 通知与前台服务：在您主动开始拨测后显示进度，并提供暂停/取消；任务结束后停止。
  • 局域网相关权限（如适用）：仅用于您对本地网络目标发起的拨测，不会扫描或上传局域网设备列表。

数据共享

我们不会与第三方共享应用内保存的拨测数据。若您使用系统分享功能导出 CSV/JSON，文件去向由您选择的目标应用或接收方决定。

数据留存与删除

数据仅保存在您的设备上。卸载应用或清除应用数据即可删除本地记录。开发者侧没有对应的云端用户数据库可供查询或删除。

儿童隐私

本应用不以儿童为主要受众，也不会有意收集儿童的个人信息。

政策变更

若本政策有重大变更，我们将更新本页面的日期与内容。继续使用应用即表示您知悉更新后的说明。

联系方式
